Locator Chaining & has

Locate a parent based on its child element and then find another element inside that parent.

Product Cards

Find the product containing the "MacBook Pro" heading, then click its Add to Cart button.

const product = page.locator('.product').filter({
  has: page.getByRole('heading', { name: 'MacBook Pro' })
});

await product
  .getByRole('button', { name: 'Add to Cart' })
  .click();

Locator 07

first(), last() & nth()

Practice locating specific elements from a collection.

Button Collection

const buttons = page.getByRole('button');

await buttons.first().click();
await buttons.last().click();
await buttons.nth(2).click();

Remember: nth() uses a zero-based index. nth(0) = first element, nth(1) = second element, nth(2) = third element.

Playwright Locator Cheat Sheet

Recommended locator strategies for UI automation.

Locator Example Best Use Rating
getByRole() getByRole('button') Accessible UI elements ★★★★★
getByLabel() getByLabel('Username') Form controls ★★★★★
getByTestId() getByTestId('login-button') Stable automation hooks ★★★★★
getByPlaceholder() getByPlaceholder('Search') Input fields ★★★★☆
getByText() getByText('Submit') Visible text ★★★★☆
getByAltText() getByAltText('Logo') Images ★★★★☆
getByTitle() getByTitle('Close') Title attributes ★★★☆☆
locator() locator('#username') CSS selectors ★★★★★
Best Practices

Locator Strategy

✅ Prefer

page.getByRole( 'button', { name: 'Login' } )

⚠️ Avoid

page.locator( 'div:nth-child(3) > div > button' )

⭐ Remember

Prefer meaningful, stable and readable locators. Use nth() only when there is no better unique locator.
